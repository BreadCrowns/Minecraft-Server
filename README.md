## 🚀 How to Enable Free Hosting via GitHub Pages
To host these pages online so anyone can view them:
1. Go to your repository on GitHub: [https://github.com/BreadCrowns/Minecraft-Server](https://github.com/BreadCrowns/Minecraft-Server)
2. Click **Settings** (gear icon near top-right).
3. On the left sidebar, click **Pages**.
4. Under **Build and deployment** ➔ **Source**, select **Deploy from a branch**.
5. Under **Branch**, select `main` and folder `/ (root)`.
6. Click **Save**.
7. In about 1–2 minutes, your website will be live at:
   **`https://breadcrowns.github.io/Minecraft-Server/`**
